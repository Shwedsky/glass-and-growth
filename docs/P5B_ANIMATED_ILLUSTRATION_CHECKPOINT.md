# P5B — Animated Illustration Checkpoint

Status: visual direction reset after owner review of rejected P5 mixed-style diorama.

## Core rule
Glass & Growth must use one coherent painterly/cozy visual language. Interactive world objects must not look like stickers, emoji, flat prototype sprites, or a different art production from the greenhouse itself.

## Preserve
- P4 economy and discovery tree
- RU/EN localization
- finite generation logic
- hover UX and affordability cues
- event hooks

## Replace
- mixed-style gardener/bee/flower sprites
- whole-scene crossfade/morph overlays
- double-image tree transitions
- text-only helpers standing in for visual objects

## First proof
1. one authored greenhouse scene
2. tree progression that visibly reacts to tapping without ghosting
3. water animation that belongs to the scene
4. plant/flower reaction that belongs to the scene
5. subtle life/insect event using scene-matched treatment
6. no gardener until a style-matched production asset exists

Do not merge until the owner confirms the single-style visual direction works in the browser build.
